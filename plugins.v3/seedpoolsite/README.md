# SeedPool 站点支持

为 MoviePilot v3 补充 **SeedPool**（UNIT3D 框架，`seedpool.org`）站点的搜索能力。

## 解决的问题

1. **搜不到，也不报错**
   MoviePilot v3 的内置站点索引里没有 `seedpool.org`，搜索时该站点根本不会被请求，
   表现为「永远 0 条结果且没有任何报错」。本插件通过 `get_module()` 暴露插件级搜索源补上这条通路。

2. **中文片名必然 0 条**
   SeedPool 的资源以英文发布名为主，直接用中文片名搜索不会有结果。插件会把中文关键词经 TMDB
   解析成 IMDb ID 与英文片名，优先用 `?imdbId=` 做精确匹配，其次用英文片名搜索。

3. **「选择站点」弹窗里看不到该站**
   同一个内置索引还会过滤站点选择列表。插件在运行时给
   `GET /api/v1/site/media/{media_type}` 的返回值做追加，把「已启用但域名不在内置索引里」的站点补进去。
   实现方式是拦截 FastAPI 的 `run_endpoint_function`，**不修改 MoviePilot 任何源文件**，重启或更新都不会被还原。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 域名 | 默认 `https://seedpool.org/`，套 CF 或换域名时改这里 |
| Cookie | 留空则自动从「站点管理」里 seedpool 的站点记录读取，站点侧更新即可，不必两处维护 |
| 超时 / UA | 一般不用改 |

## 说明

- 站点分类按实测映射：`1=电影 2=电视剧 3=游戏 5=音乐 6=动漫 9=有声书`，其中 1 归电影，2/6 归电视剧，5 归音乐。
- 仅提供搜索能力，下载器、做种策略等仍由 MoviePilot 自身处理。
